## Project Summary (page 2)

### 1.1 Major Objectives

The goal of this project is to produce an AutoLISP program to generate data files for a shoe sole mold pouring machine. The program is to use AME solid models of the moldings. The output file is to be a space delimited text file.

All work will has been done within the AutoDESK environment including AutoCAD, AutoLISP, AME, and AutoCAD 3D Studio. The objectives of this project have been met. I have found that AutoCAD is a very powerful tool. Most people think of AutoCAD as a drafting program. This is not true. AutoCAD can be used for a wide variety of applications, and is highly customizable, as I will show in this report.
